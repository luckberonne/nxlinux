      python3 tools/agentmsg.py --as YOUR_NAME commit -m "one plain line" PATH...
    which commits exactly the paths you name and refuses paths another agent has claimed.
  - Before editing something outside your own area:  python3 tools/agentmsg.py --as YOUR_NAME claim PATH... --note "why"

  - When you stop:  python3 tools/agentmsg.py --as YOUR_NAME send --to all --kind handoff -m "done / not done / files / next"
